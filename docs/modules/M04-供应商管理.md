# M04 供应商管理

> 覆盖：#20、#29（供应商资料模板） | 依赖：M02、M03

## 1. 目标

供应商主数据（分类必填：战略/优秀/普通）、主营材料分类、联系方式与邮件语言、Excel 导入导出、供应商分类维护、门户账号开通与激活。

## 2. 范围

**范围内**：供应商 CRUD、启停用；供应商分类页（`supplier_category` 字典的专用入口）；主营材料分类；`supplier.contact` 脱敏；标准 Excel 导入导出；门户账号（开通、重发激活邮件、启停用）与激活页；邮件模板 `account.activate`；seed 06 §2.8。

**范围外**：供应商的报价记录与积分页签（M15 在供应商详情上补充）。

## 3. 规则

| 编号 | 规则 |
|---|---|
| R04-1 | 分类必填，必须是启用的 `supplier_category` 字典项（#20 主数据必填分类）。 |
| R04-2 | code 可手填（唯一），留空自动生成 `SUP10001` 起的编号；信用代码可空，填写时必须是 18 位大写字母或数字且唯一。 |
| R04-3 | 联系人、联系邮箱必填；抄送邮箱最多 5 个；首选语言为 `zh-CN` / `en-US` / `bilingual`，决定邮件语言（#4）。 |
| R04-4 | 主营材料分类可多选，只能选有效启用的分类。 |
| R04-5 | 列表筛选：关键字（编码、中英文名、联系人）、分类（多选，战略/优秀/普通可过滤）、主营材料分类（含下级）、状态。 |
| R04-6 | 停用供应商：其门户用户的会话立即删除且不能再登录；不能被新邀请（M07）；已有报价单和合同不受影响。 |
| R04-7 | 没有 `supplier.contact` 字段权限的用户看到的联系电话、联系邮箱、抄送邮箱为脱敏状态（列表、详情、导出都适用）。 |
| R04-8 | Excel 列依次为：供应商编码、供应商名称 *、英文名称、统一社会信用代码、供应商分类 *、主营材料分类编码（英文逗号分隔）、联系人 *、联系邮箱 *、联系电话、首选语言、国家/地区、地址、备注（表头均为"中文 / English"）。分类接受字典编码或中英文名称；首选语言接受 `zh-CN`/`en-US`/`bilingual` 或"中文/English/中英"；编码存在则更新，否则新建；全部校验通过才写入。 |
| R04-9 | 供应商分类页：可新增、改名、排序、停用分类；系统预置的三个分类不可删除。 |
| R04-10 | 开通门户账号：输入邮箱和姓名，邮箱在全部用户中唯一（`SUPPLIER_ACCOUNT_EXISTS`），供应商必须启用；创建 `User(userType = SUPPLIER, status = PENDING_ACTIVATION, 角色 SUPPLIER)` 并发送激活邮件（令牌 7 天有效，语言按供应商首选语言）。重发激活会使旧令牌失效。 |
| R04-11 | 激活：用有效令牌设置密码 → `ACTIVE`；令牌无效/过期/已用返回 `AUTH_TOKEN_INVALID`。 |
| R04-12 | 新建、编辑、启停用、导入、账号操作都记审计。 |

## 5. 前端

- `/suppliers`：筛选栏（关键字、分类多选、主营材料分类、状态）+ 按钮"新增 / 导入 Excel / 导出 Excel" + 表格（编码、名称、分类标签、主营分类、联系人、联系电话（可能脱敏）、语言、状态、操作），参考 PPT #20。
- `/suppliers/:id`：基本信息卡片 + 页签"门户账号"（列表、开通、重发激活、启停用）；M15 再加"报价记录 / 积分"。
- 新建/编辑对话框：主营材料分类用 `CategoryTreeSelect` 多选。
- `/suppliers/categories`：分类表格（编码、中文名、英文名、排序、状态）。
- `/activate?token=`：设置密码页（双语），成功后跳登录。

## 6. 测试

- 分类必填；信用代码格式与唯一；自动编码。
- 筛选：按分类多选、按主营分类（含下级）。
- 脱敏：PD 角色看供应商联系方式为 null 且 `maskedFields` 正确。
- 导入：语言"中英"映射为 bilingual；分类中文名匹配；邮箱格式错误整表拒绝。
- 账号：开通 → Mailpit/log 中有激活邮件 → 激活 → 能登录门户；重复邮箱被拒；停用供应商后其账号登录返回 `AUTH_ACCOUNT_DISABLED`。

## 7. 验收

- [ ] 供应商可以按战略/优秀/普通过滤，分类在新建时必填。
- [ ] 给 SUP10008 开通账号，用激活邮件里的链接设置密码并登录门户。
- [ ] 导入导出往返一致。
