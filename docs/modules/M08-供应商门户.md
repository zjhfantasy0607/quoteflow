# M08 供应商门户

> 覆盖：#5、#28（权限隔离） | 依赖：M07

## 1. 目标

供应商登录门户后只看到邀请了自己的询价，在线预览和下载规格书与产品图，每次预览/下载都记日志；采购方可以查看下载日志。建立供应商隔离的测试集。

## 2. 范围

**范围内**：`PortalLayout` 与菜单；门户首页（简单计数，M16 完善）；我的询价列表；报价详情页的"询价信息"和"规格附件"部分；首次查看记录；询价附件的文件访问解析器（供应商侧）与 `FileAccessLog`；采购方"下载日志"页签；企业资料（只读）；账号设置（改密码、语言）；隔离 e2e 测试集。

**范围外**：报价填写（M09）、议价（M11）。

## 3. 规则

05 §7.2 的 P-1 至 P-6 全部适用，另外：

| 编号 | 规则 |
|---|---|
| R08-1 | 列表只含本供应商的报价单，且所在轮次已发布。页签：待处理（轮次 `WAITING_QUOTES`）/ 评标中（`QUOTES_CLOSED`、`OPENED`）/ 已结束（`EVALUATED`、`SUPERSEDED`、`CANCELLED`）。 |
| R08-2 | 打开报价详情时，`firstViewedAt` 为空则写入当前时间（响应状态里的"已查看"）。 |
| R08-3 | 附件预览（PDF 内嵌、图片、xlsx 表格）和下载都写 `FileAccessLog`（action = PREVIEW / DOWNLOAD，带 supplierId、inquiryId）；内部用户访问询价附件同样记录（supplierId 为空）。 |
| R08-4 | 采购方在询价详情"下载日志"页签看到：时间、供应商、用户、文件名、动作（需要 `inquiry:accessLog`）。 |
| R08-5 | 门户接口访问别家的报价单返回 404；访问未受邀询价的附件返回 403 `FILE_ACCESS_DENIED`；供应商访问任何内部接口返回 403。 |
| R08-6 | 已作废的旧轮次报价单可以只读查看（规格和自己的报价），页面标明"已作废 / 第 N 轮"。 |
| R08-7 | 门户详情展示的字段按 P-5，项目号、草稿号、审批记录、内部备注一律不返回。 |

## 4. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/portal/quotes` | SupplierOnly | `tab`、keyword；分页 |
| GET | `/api/portal/quotes/:quoteId` | SupplierOnly | 询价信息、轮次信息（含变更说明）、询价行、附件、报价状态、`allowedActions`（M09 起有内容）；首次访问写 `firstViewedAt` |
| GET | `/api/portal/profile` | SupplierOnly | 企业资料（本供应商） |
| GET | `/api/inquiries/:id/file-access-logs` | `inquiry:accessLog` | 分页 |

附件预览/下载走 `GET /api/files/:id/content`（解析器按 P-3 判断）。改密码、改语言复用 `/api/auth/me/*`。

## 5. 前端

- `PortalLayout`：顶栏显示公司名称（来自 `company.profile`）、"供应商门户 / Supplier Portal"、语言切换、用户菜单；左侧菜单：首页、我的询价、企业资料、账号设置。
- `/portal/quotes`：页签 + 表格（正式询价号、标题、轮次、截止时间（倒计时，过期标红）、我的状态、最后提交时间）。
- `/portal/quotes/:quoteId`：询价信息卡片（正式询价号、标题、币种、截止时间、采购联系人）+ 变更说明（第 2 轮起）+ 询价行表格 + 规格附件列表（文件名、大小、上传时间、"在线预览 / 下载"，提示"下载会被记录"，参考 PPT #5）。M09 在此页增加报价部分。
- `/portal/profile`：只读企业资料。`/portal/account`：修改密码、语言。
- 询价详情"下载日志"页签。

## 6. 测试（隔离测试集 `portal-isolation.e2e-spec.ts`）

- 供应商 A 列表看不到只邀请了 B 的询价；GET B 的报价单 → 404。
- A 访问 B 所在询价的附件 → 403；访问未发布轮次的附件 → 403（构造：被邀请但轮次为 DRAFT 的情况不存在，改为访问别的询价的附件）。
- 供应商用户访问 `/api/inquiries`、`/api/suppliers`、`/api/system/users` → 403。
- 门户详情响应体中不存在 `projectNo`、`draftNo`、审批记录等字段（对响应 JSON 做键扫描）。
- 预览和下载各写一条日志；采购方能查到；没有 `inquiry:accessLog` 的用户被拒。
- 首次查看只写一次。
- 供应商被停用后会话失效。

## 7. 验收

- [x] 采购方在下载日志里看到这些记录。
- [x] 门户切换到 English 后所有界面文字为英文。

## 8. 实施步骤

1. api：portal controller（`@SupplierOnly`）→ 列表与详情 → 首次查看 → 文件解析器（供应商侧 + 记录日志）→ 下载日志接口。
2. 隔离测试集。
3. 前端门户布局与页面 → 下载日志页签 → verify，更新进度。
