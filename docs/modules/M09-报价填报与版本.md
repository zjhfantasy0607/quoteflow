# M09 报价填报与版本

> 覆盖：#6、#9 | 依赖：M05、M08

## 1. 目标

供应商按该轮冻结的 PPL 模板在线填报（或下载锁定 Excel 填好导入），可保存草稿、提交、在截止前反复更新（以最后一次为准，历史版本可查），或拒绝报价（必填原因）。采购方此时只能看到提交状态。

## 2. 范围

**范围内**：门户报价表单（`PplLineTable` + `PplForm` 抽屉）、草稿保存、提交生成版本、拒绝、版本历史、锁定 Excel 下载与导入、报价附件；截止时间的服务端校验；`computePortalQuoteActions()`；报价版本附件的文件解析器；审计（不含金额）；演示场景 D3。

**范围外**：截止任务与开标（M10）；采购方查看报价内容（M10 起，开标后）。

## 3. 规则

| 编号 | 规则 |
|---|---|
| R09-1 | 只有轮次 `WAITING_QUOTES`、服务端当前时间 < 截止、报价单不是 `VOID` 时，才能保存草稿、提交、拒绝；否则 `QUOTE_DEADLINE_PASSED` 或 `QUOTE_INVALID_STATUS`。**不依赖截止任务是否已执行。** |
| R09-2 | 表单列来自该轮冻结的模板版本和变体（`resolveColumns`）；预填列只读、取自询价行；公式列只读、实时计算；必填列标 `*`；标签按当前语言。 |
| R09-3 | 新草稿用列的 `default` 初始化（税率 13）。草稿保存只校验格式（`QUOTE_VALUES_INVALID`），存入 `draftValues`（`source = 'ONLINE'`）。 |
| R09-4 | 提交：完整校验（含必填）→ 服务端重算公式列 → 计算 `totalAmount` → 新建 `QuoteVersion`（`versionNo + 1`，`source` 取草稿来源，默认 ONLINE）→ 更新 `currentVersionId`、`lastSubmittedAt`，首次响应写 `respondedAt`，状态 `SUBMITTED`，清空拒绝信息和草稿；草稿里的附件转成该版本的 `Attachment`。 |
| R09-5 | 截止前可以多次提交，每次一个新版本；当前版本 = 最后一次提交（#9 截止前以最后一次为准）。 |
| R09-6 | 拒绝：原因编码（`decline_reason` 字典）和说明（1–500 字）必填（`QUOTE_DECLINE_REASON_REQUIRED`）；状态 `DECLINED`。截止前可以撤销拒绝重新提交，也可以提交后改为拒绝。 |
| R09-7 | 供应商随时能看到自己的全部版本；采购方开标前只能看到状态（S-1，M10 完整实现）。 |
| R09-8 | 锁定 Excel：下载时预先写入当前草稿（没有草稿则写当前版本）的取值；导入只写草稿（`source = 'EXCEL'`），不自动提交；错误按 04 §7.4 返回并在页面逐条显示。 |
| R09-9 | 报价附件（`ATTACHMENT`）每次最多 10 个；开标前采购方不能下载（S-3）。 |
| R09-10 | 审计记录"提交了第 N 版 / 拒绝报价 / 导入 Excel 草稿"，不写金额。 |
| R09-11 | 前端提交前做同样的校验，并定位到第一个出错的行和字段（打开对应行的抽屉并滚动到该字段）。 |

## 4. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/portal/quotes/:quoteId` | SupplierOnly | 在 M08 基础上增加：解析后的列、草稿、当前版本取值、`allowedActions` |
| PUT | `/api/portal/quotes/:quoteId/draft` | SupplierOnly | `{ lines, remark?, changeNote?, attachmentFileIds? }` |
| POST | `/api/portal/quotes/:quoteId/submit` | SupplierOnly | 同上结构，返回新版本 |
| POST | `/api/portal/quotes/:quoteId/decline` | SupplierOnly | `{ reasonCode, reason }` |
| GET | `/api/portal/quotes/:quoteId/versions` | SupplierOnly | 版本列表（版本号、提交时间、合计、来源、备注） |
| GET | `/api/portal/quotes/:quoteId/versions/:versionNo` | SupplierOnly | 版本详情 |
| GET | `/api/portal/quotes/:quoteId/excel-template` | SupplierOnly | 锁定 Excel |
| POST | `/api/portal/quotes/:quoteId/excel-import` | SupplierOnly | multipart → 草稿或 422 |

## 5. 前端

- 门户报价详情页增加"报价"区：
  - 顶部提示"截止时间前可多次更新，系统以最后一次提交为准"（参考 PPT #6、#9）+ 倒计时。
  - 两种方式并列：①在线填写：`PplLineTable`（每行显示 `keyField` 列，供应商列可直接改，"编辑全部字段"打开 `PplForm` 抽屉，按分组折叠显示全部列）；②Excel：下载锁定模板、导入（`ExcelImportDialog` 复用，错误显示行号和列名）。
  - 合计（含税）实时显示；备注、变更说明、附件上传。
  - 按钮：保存草稿、提交报价、拒绝报价（对话框选原因 + 填说明）。按 `allowedActions` 显示。
- "历史版本"区：时间线（版本号、提交时间、含税合计、来源、备注），点开看只读的版本明细（参考 PPT #9）。
- 截止后整个报价区只读，显示"已截止"。
- 组件：`PplLineTable`、`PplForm`、`PplValueDisplay`（只读显示，处理脱敏），后面比价矩阵、合同快照复用。

## 6. 测试

- 提交 → 版本 1；再提交 → 版本 2，当前版本指向 2；`respondedAt` 只在第一次写。
- 公式：客户端传入错误的公式列值被忽略，服务端重算结果正确；`totalAmount` 正确。
- 必填缺失时提交被拒并返回行号和 key；草稿保存不校验必填。
- 拒绝：缺原因被拒；拒绝后再提交成功、状态变回 `SUBMITTED`。
- 截止：TestClock 越过截止（截止任务未执行）后提交、保存草稿、拒绝都返回 `QUOTE_DEADLINE_PASSED`。
- Excel：下载的模板包含已填草稿值；修改后导入写入草稿且 `source = 'EXCEL'`，提交后版本来源为 EXCEL；错误文件整表拒绝。
- 采购方此时调用响应列表只拿到状态字段，调用报价版本接口返回 `QUOTE_SEALED`（完整的密封测试集在 M10）。

## 7. 验收

- [ ] 供应商在线填写 70 列中的必填项提交，再改价格重新提交，历史版本里有两版。
- [ ] 下载锁定 Excel，受保护的列改不了；填好导入后在页面看到数据，提交成功。
- [ ] 拒绝报价必须填原因。

## 8. 实施步骤

1. shared：门户报价 schema、DTO、`PortalQuoteAction`。
2. api：草稿 → 提交（事务、版本号、公式、附件）→ 拒绝 → 版本查询 → Excel 下载导入（调用 `PplExcelService`）→ 报价附件解析器 → 审计。
3. e2e → 演示场景 D3。
4. 前端：`PplLineTable`、`PplForm` → 报价区 → 历史版本 → verify，更新进度。
