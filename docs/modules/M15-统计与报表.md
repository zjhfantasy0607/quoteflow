# M15 统计与报表

> 覆盖：#13–17（四类辅助统计，可导出）、#26（询报价单统计、物流报价明细、供应商积分统计与积分流水） | 依赖：M12

## 1. 目标

统计看板四张图（年询盘项目数与品类、供应商响应速度、中选次数与成功率、询盘周期时效），四张报表，全部可筛选、可导出；供应商积分的手工调整；为图表生成约 60 张历史演示数据。

## 2. 范围

**范围内**：统计接口与看板页、统计导出；四张报表的接口、页面、导出；积分手工调整；供应商详情的"报价记录 / 积分"页签；`seed-demo.ts` 的历史数据 H；把报表加入密封测试集。

## 3. 指标口径

所有日期按 UTC+8 归属到日/月。筛选"材料分类"时包含下级；"供应商分类"按 `Supplier.categoryCode`。数据量为千级，全部在服务端用 JS 聚合。

| 指标 | 口径 |
|---|---|
| **年询盘项目数与品类**（#13、#14） | 按月统计：第 1 轮 `publishedAt` 落在该月的询价单数、其中不同 `projectNo` 的个数（项目数）、涉及的不同**顶级**材料分类个数（品类数，取询价行分类的顶级祖先）。另给全年按顶级材料分类的询价单数分布。默认当年。 |
| **供应商响应速度**（#15） | 以报价单为单位，`invitedAt` 落在区间内：响应时长 = `respondedAt − invitedAt`。分布桶：≤2 小时、2–8 小时、8–24 小时、1–3 天、>3 天、未响应（截止时仍为 `INVITED`）。另给每家供应商：邀请数、响应数、响应率、平均响应时长。被作废（`VOID`）的报价单只要已响应仍计入，未响应的不计入。 |
| **中选次数与成功率**（#16） | 以 `EVALUATED` 的轮次为单位，`evaluatedAt` 落在区间内：按月统计中标次数（= 轮次数）、成功率 = 中标数 ÷ 参与评标的报价单数（`WON + LOST`）。另给每家供应商：受邀数、报价数（曾提交过的报价单）、中标数、中标率 = 中标数 ÷ 报价数。 |
| **询盘周期时效**（#17） | 以完成的询价单为单位，`completedAt` 落在区间内：周期天数 = `completedAt − 第 1 轮 publishedAt`（保留 1 位小数）。分布桶：≤3 天、4–7 天、8–14 天、15–30 天、>30 天；另给按月的平均周期。 |

图表形式参考 PPT #13：项目数柱状 + 品类数折线（双轴）；响应速度柱状（占比 %）；中选次数柱状 + 成功率折线；周期时效横向条形图（占比 %）。

## 4. 报表

| 报表 | 一行是什么 | 列 | 筛选 |
|---|---|---|---|
| 询报价单统计 | 一个已发布的轮次 | 正式询价号、轮次、标题、项目号、材料类别、状态、受邀家数、有效报价数（提交过）、最低/最高/平均含税合计、中标供应商、负责人、发布时间 | 询价号、状态、发布时间区间、供应商（参与过）、负责人、材料类别 |
| 物流报价明细（A-09） | 一个开过标的轮次中，一家供应商当前版本的一个询价行 | 正式询价号、轮次、供应商、行号、物料、PPL 中 `logistics: true` 的 13 列、量产交期 | 同上 + 供应商 |
| 供应商积分统计 | 一家供应商 | 编码、名称、分类、累计积分、区间内积分、按规则分项（准时报价、快速响应、中标、未响应、手工调整）、最近变动时间 | 供应商分类、时间区间、关键字 |
| 积分记录流水 | 一条积分条目 | 时间、供应商、规则、分值、来源（自动/手工）、关联询价号、备注、操作人 | 供应商、规则、时间区间 |

- **密封**：询报价单统计中未开标轮次的金额列显示 🔒；物流报价明细只包含开过标的轮次（S-3）。
- **脱敏**：金额列按 `quote.amount`；没有权限时导出写"***"。

## 5. 规则

| 编号 | 规则 |
|---|---|
| R15-1 | 指标严格按 §3 口径计算，接口返回原始数值，前端负责格式化。 |
| R15-2 | 统计导出：一个 xlsx，每张图一个 sheet（含图表对应的数据表）；报表导出：当前筛选条件下的全部行（上限 10000 行）。需要 `report:export`。 |
| R15-3 | 手工调整积分：`points:adjust`；分值为非零整数，备注必填（`POINTS_REMARK_REQUIRED`）；记审计。 |
| R15-4 | 供应商详情"报价记录"列出该供应商参与过的报价单（询价号、轮次、状态、提交时间；金额受密封与脱敏约束）；"积分"列出流水。 |
| R15-5 | 历史演示数据 H 必须满足 02 §3 的不变量，项目号以 `HIST-` 开头。 |

## 7. 前端

- `/stats`：顶部筛选（日期区间、材料分类、供应商/供应商分类）+ 查询、重置、导出；2×2 四张 ECharts 图（参考 PPT #13）；每张图下可展开对应的数据表（如每家供应商的响应率、中标率）。
- `/reports`：四个页签（参考 PPT #26），每个页签筛选 + 表格 + 导出；积分流水页签有"手工调整"按钮。
- 供应商详情增加"报价记录""积分"页签。

## 8. 测试

用固定夹具（已知的邀请、响应、中标、完成时间）断言：

- 每个指标的数值与分桶（含边界：恰好 2 小时归入"≤2 小时"，恰好 3 天归入"≤3 天"）。
- UTC+8 归月：UTC 时间 2026-10-31 17:00 归入 11 月。
- 材料分类筛选包含下级。
- 报表：未开标轮次金额被密封（加入密封测试集）；无 `quote.amount` 时金额为 null、导出为"***"。
- 积分调整：备注必填；流水与汇总一致。
