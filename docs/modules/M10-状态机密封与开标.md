# M10 状态机、密封与开标

> 覆盖：#23（等待报价 → 报价完成 → 开标 → 评标完成；开标前密封；状态与操作权限绑定）、#23 补充、#24（评标中） | 依赖：M09

## 1. 目标

截止自动进入"报价完成"，采购主管开标；开标前严格密封，采购方只看提交状态；开标后报价进入"评标中"，结算响应类积分，通知已报价的供应商。建立覆盖所有报价数据出口的密封测试集。

## 2. 范围

**范围内**：`roundDeadline` 任务；提前截止；开标；`SealService` 与参数 `seal.preOpenViewRoles`；采购方"供应商响应"页签的密封视图（参考 PPT #23 补充：金额位置显示锁）；开标后的报价详情与版本查看（采购方）；报价附件的内部侧解析器（受密封约束）；积分服务的写入部分（`PointsService.award()`，规则读 `points.rules`）；邮件模板 `opening`；轮次状态进度条组件；密封 e2e 测试集。

**范围外**：比价矩阵（M11）；积分报表（M15）。

## 3. 规则

| 编号 | 规则 |
|---|---|
| R10-1 | 截止任务每分钟把"`WAITING_QUOTES` 且现在 ≥ 截止"的轮次改为 `QUOTES_CLOSED`（条件更新，幂等）。 |
| R10-2 | 提前截止：需要 `inquiry:open`，且全部报价单都已响应，否则 `ROUND_NOT_ALL_RESPONDED`。 |
| R10-3 | 开标：仅 `QUOTES_CLOSED` 可开（`ROUND_INVALID_STATUS`），需要 `inquiry:open`；`SUBMITTED` → `EVALUATING`；`INVITED`（未响应）和 `DECLINED` 保持不变。 |
| R10-4 | 开标时结算积分（`bizKey` 防重复）：每个 `SUBMITTED` 的报价单 +`quoteOnTime`；其中 `respondedAt − invitedAt ≤ fastResponseHours` 小时的再 +`fastResponse`；每个 `INVITED` 的报价单 +`noResponse`（负数）。`DECLINED` 不加不减。 |
| R10-5 | 开标邮件只发给 `EVALUATING` 的供应商，告知已开标进入评标，不含任何金额或其他供应商信息。 |
| R10-6 | 密封规则 S-1 至 S-6（05 §7.1）全部由 `SealService.canViewQuoteContent()` 判定，适用于本模块及以后所有返回报价内容的接口。 |
| R10-7 | 开标后的报价详情、版本详情、附件下载需要 `inquiry:evaluate`；金额列按 `quote.amount` 脱敏。 |
| R10-8 | 状态与操作绑定：每个动作接口都通过 `assertAction()` 复核轮次状态和权限；前端只按 `allowedActions` 显示按钮。 |

## 5. 前端

- 询价详情顶部的轮次进度条：等待报价 → 报价完成 → 开标 → 评标完成（参考 PPT #23），当前步骤高亮，显示各步时间。
- "供应商响应"页签：开标前顶部提示"开标前不可见金额"，金额、交期等列显示 🔒 `******`（参考 PPT #23 补充）；开标后显示合计并可点进报价详情（只读 `PplLineTable` + 版本历史）。
- 操作按钮：提前截止（全部已响应时可用）、开标（确认对话框）。

## 6. 测试（密封测试集 `sealing.e2e-spec.ts`）

构造：一轮 3 家供应商，2 家已提交（含附件）、1 家未响应。

- 开标前，分别用 BUYER、PURCHASE_MANAGER、ADMIN 调用：响应列表（无金额字段、无版本内容）、报价详情（403 `QUOTE_SEALED`）、版本详情（403）、报价附件下载（403）、审计时间线（不含金额）、邮件表中发给内部用户的邮件正文（不含金额）——全部通过。M11 加入比价矩阵与导出，M15 加入报表，各自补用例到这个测试集。
- 把 `PURCHASE_MANAGER` 写进 `seal.preOpenViewRoles` 后，主管开标前可以看到报价详情；移除后又不可见。
- 截止任务：TestClock 越过截止 → 执行任务 → `QUOTES_CLOSED`，`Inquiry.currentRoundStatus` 同步；重复执行无副作用。
- 提前截止：有未响应者时被拒；全部响应后成功。
- 开标：非 `QUOTES_CLOSED` 被拒；成功后报价单状态正确、积分条目正确（准时、快速、未响应）、开标邮件只发给已报价者；并发开标两次只成功一次。
- 开标后：采购员能看报价详情；去掉其 `quote.amount` 字段权限后金额列为 null 且 `maskedFields` 正确。

## 7. 验收

- [ ] 截止前采购方在"供应商响应"里只看到"已提交 / 已拒绝 / 未响应"，金额处显示锁。
- [ ] 截止后状态自动变为"报价完成"，采购主管开标后能看到各家报价。
