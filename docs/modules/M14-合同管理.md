# M14 合同管理

> 覆盖：#25 | 依赖：M12

## 1. 目标

中标后自动生成的合同草稿可以补充交付与付款条款、上传附件，经"合同审核 → 合同批准"两步审批；合同带询价/报价快照，可打印；本期不做电子签，批准后线下纸质签订，扫描件可选上传。

## 2. 范围

**范围内**：合同列表、详情、编辑；提交、审核、批准（通过/驳回）；审批记录；邮件模板 `contract.reviewRequest`、`contract.approveRequest`、`contract.result`；打印视图；签字扫描件上传；合同附件与扫描件的文件解析器；`contract.amount` 脱敏；数据权限（跟随询价单）；`computeContractActions()`；演示场景 D7。

## 3. 规则

| 编号 | 规则 |
|---|---|
| R14-1 | 状态流转严格按 05 §6。 |
| R14-2 | 只有 `DRAFT` 可编辑：交付日期、交付地点、付款方式、合同摘要、备注、附件（`ATTACHMENT`，最多 20 个）。金额、币种、供应商、快照不可编辑。 |
| R14-3 | 提交审核时交付日期、交付地点、付款方式必填（`CONTRACT_FIELDS_REQUIRED`）。 |
| R14-4 | 驳回（审核或批准环节）意见必填（`CONTRACT_COMMENT_REQUIRED`），回到 `DRAFT`；每次提交、通过、驳回都写 `ContractApproval`。 |
| R14-5 | 审核请求发给数据权限覆盖该合同的 `contract:review` 用户；批准请求发给 `contract:approve` 用户；结果发给最近一次的提交人。 |
| R14-6 | `APPROVED` 后可上传签字扫描件（PDF/图片），记录 `signedAt`；可以替换。 |
| R14-7 | 合同的数据权限与其询价单相同；金额按 `contract.amount` 脱敏（快照中的金额同样处理）。 |
| R14-8 | 打印视图只用快照数据渲染，与当前主数据无关。 |
| R14-9 | 所有动作记审计。 |

## 4. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/contracts` | `contract:view` | 筛选：status、keyword（合同号/询价号/供应商）、supplierId、from、to |
| GET | `/api/contracts/:id` | `contract:view` | 含快照、审批记录、附件、`allowedActions` |
| PUT | `/api/contracts/:id` | `contract:edit` | |
| POST | `/api/contracts/:id/submit` | `contract:edit` | |
| POST | `/api/contracts/:id/review` | `contract:review` | `{ action: 'APPROVE' \| 'REJECT', comment? }` |
| POST | `/api/contracts/:id/approve` | `contract:approve` | 同上 |
| POST | `/api/contracts/:id/signed-scan` | `contract:edit` | `{ fileId }` |

## 5. 前端

- `/contracts`：页签（全部/草稿/待审核/待批准/已批准）+ 表格（合同号、询价号、供应商、金额、状态、创建时间）。
- `/contracts/:id`：左侧合同信息与快照（询价信息、询价行与中标报价的关键列、议价摘要），右侧状态步骤条（合同审核 → 合同批准，参考 PPT #25）、审批记录时间线、附件；按 `allowedActions` 显示"编辑 / 提交审核 / 审核通过 / 驳回 / 批准 / 上传签字扫描件 / 打印"。提示条"本期不做电子签，合同审批完成后以纸质签订为准"。
- `/contracts/:id/print`：A4 打印版（`@media print`）：合同号、甲乙双方、询价号、明细表（行号、物料、规格、数量、单位、含税单价、含税总价）、合计（含大写金额）、交付与付款条款、签字盖章栏。

## 6. 测试

- 流转全路径：提交 → 审核驳回 → 修改再提交 → 审核通过 → 批准驳回 → 再提交 → 审核通过 → 批准。
- 必填项、驳回意见、非法状态动作。
- 邮件收件人正确。
- 数据权限：SELF 采购员看不到别人的合同；脱敏后金额为 null。
- 扫描件上传与文件访问权限。

## 7. 验收
