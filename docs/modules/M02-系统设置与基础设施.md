# M02 系统设置与基础设施

> 覆盖：#27（数据字典、管理员维护立即生效）、#29（通用导入导出工具）、#4（邮件基础设施）、#5（文件基础设施） | 依赖：M01

## 1. 目标

把后续业务模块共用的基础能力做完：字典、系统参数、业务编号、文件上传与受控下载、邮件发件箱、标准 Excel 模板、定时任务、操作日志查看、找回密码。

## 2. 范围

**范围内**

1. 数据字典：类型与字典项 CRUD；`GET /api/dicts?types=` 给前端取启用项；前端 `dict` store、`DictSelect`、`DictTag`。seed 写入 06 §2.3 全部字典。
2. 系统参数：shared `params.ts`（05 §8 的 key、默认值、zod schema、中英说明）；`ParamsService.get/set`；参数页；`GET /api/public/app-config`（公司名称、上传限制，未登录也能取）。
3. `SequenceService`：01 §13 的编号格式。
4. 文件：`StorageDriver` + `LocalStorageDriver`；`POST /api/files`；访问策略注册表 `FileAccessPolicyRegistry`；`GET /api/files/:id/content`、`/meta`、`/sheet-preview`；`FileAccessLog` 写入接口（由解析器决定是否记录）；前端 `FileUploader`、`FilePreview`。
5. 邮件：`MailService.enqueue()`、模板注册与公共版式（公司名抬头、页脚"本邮件由系统自动发送"）、`smtp` / `log` 两种传输、`mailOutbox` 任务、邮件记录页（筛选 + 详情预览 + 重发）。本模块实现模板 `account.resetPassword`。
6. Excel：`ExcelTemplateService`（标准模板生成、导出、严格解析），前端 `ExcelImportDialog`。
7. 定时任务框架：`JobsModule`，`JOBS_ENABLED` 开关，防重入；`cleanup` 任务（过期会话/令牌、24 小时未被引用的文件）。
8. 操作日志查看页。
9. 找回密码：`forgot-password` / `reset-password` 接口与页面。

**范围外**：各业务模块自己的邮件模板、文件解析器、导入模板定义。

## 3. 规则

| 编号 | 规则 |
|---|---|
| R02-1 | 系统字典类型不可删除；系统类型下的字典项不可删除，只能停用；字典项 code 创建后不可改。 |
| R02-2 | 字典和参数修改后立即生效（服务端不缓存或修改时清缓存）；前端 `dict` store 在字典管理页保存后刷新。 |
| R02-3 | 参数按各自 zod schema 校验（`PARAM_INVALID`）；未知 key 返回 404。 |
| R02-4 | 上传按 kind 校验扩展名、魔数、大小：`SPEC_DOC` = pdf/xlsx/xls/jpg/png/webp，≤ `specDocMaxMB`；`PRODUCT_IMAGE`、`MATERIAL_IMAGE` = jpg/png/webp，≤ `imageMaxMB`；`ATTACHMENT` = pdf/xlsx/xls/docx/doc/jpg/png/webp/zip，≤ `attachmentMaxMB`。魔数：PDF `%PDF-`、PNG `89 50 4E 47`、JPEG `FF D8 FF`、WebP `RIFF....WEBP`、xlsx/docx/zip `PK 03 04`、xls/doc `D0 CF 11 E0`。 |
| R02-5 | 文件只能通过访问策略读取；没有解析器放行时，仅"上传者本人且文件未被引用"可读，否则 `FILE_ACCESS_DENIED`。 |
| R02-6 | sheet-preview 只支持 xlsx，每个 sheet 最多 200 行 × 50 列，单元格转成字符串。 |
| R02-7 | 邮件在业务事务内入队、入队即渲染；`bizKey` 重复时静默跳过；发送失败按 1/5/15/60/180 分钟重试，第 5 次失败置 `FAILED`；"重发"把状态改回 `PENDING`、`attempts` 清零。 |
| R02-8 | 邮件语言：供应商取 `preferredLanguage`，内部用户取 `locale`；`bilingual` 时主题"中文 / English"，正文中文在上英文在下。邮件里的时间按 01 §10 格式写明时区。 |
| R02-9 | 标准 Excel 导入：表头（规范化空白和全角斜杠后）必须与模板的名称和顺序完全一致，否则 `EXCEL_HEADER_MISMATCH` 整表拒绝；跳过全空行；任何一行有错就 `EXCEL_ROWS_INVALID`，一行都不导入；超过 5000 行 `EXCEL_TOO_MANY_ROWS`；不做智能识别（#29）。 |
| R02-10 | 编号并发安全（同一时刻 20 个请求取号不重复）。 |
| R02-11 | 找回密码：无论邮箱是否存在都返回 200；令牌 1 小时有效、只能用一次；重置后删除该用户全部会话。 |
| R02-12 | 字典、参数的修改记审计；操作日志页只读。 |

## 5. 前端

- `/system/dicts`：左侧字典类型列表（系统类型带标识），右侧字典项表格（编码、中文名、英文名、排序、状态、操作），参考 PPT #27。
- `/system/params`：每个参数一张卡片，按类型渲染表单（数字、开关、角色多选、JSON 结构化表单），显示中英说明与默认值。
- `/system/emails`：筛选栏（日期区间、类型、语言、状态、收件人）+ 表格（类型、收件人/供应商、语言、发送时间、状态、尝试次数）+ 详情抽屉（主题、收件人、抄送、HTML 预览用 sandbox iframe、错误信息、重发按钮），参考 PPT #4。
- `/system/audit`：筛选 + 表格（时间、操作人、动作、对象、摘要）。
- `/forgot-password`、`/reset-password?token=`。
- 组件：`DictSelect`、`DictTag`、`FileUploader`、`FilePreview`、`ExcelImportDialog`（下载模板 → 选文件 → 上传 → 成功提示，或分"表头错误 / 行错误"两种列表展示）。

## 6. 测试

- 字典：系统项删除被拒；code 不可改；停用后 `/api/dicts` 不返回。
- 参数：非法值被拒；修改后 `ParamsService.get` 立刻返回新值。
- 文件：扩展名伪装（把 exe 改名为 pdf）被魔数拦截；超大小被拒；未被引用的文件只有上传者能读；`Content-Disposition` 中文文件名正确。
- 邮件：`log` 传输下入队 → 任务发送 → `SENT`；模拟失败重试的时间点和第 5 次 `FAILED`；`bizKey` 去重；bilingual 渲染包含中英两段。
- Excel：表头缺列、多列、顺序错分别报出；有错误行时整表不导入；空行跳过；5001 行被拒。
- 编号：并发取号不重复，格式正确，月/日切换后从 0001 重新开始。
- 找回密码：不存在的邮箱也返回 200 且不发邮件；令牌过期、重复使用被拒；重置后旧会话失效。
