# M06 询价单与审批

> 覆盖：#1、#2、#22，以及 #21（询价行关联分类）、#31（从材料库选用）、#29（询价行导入） | 依赖：M03、M05

## 1. 目标

以项目号创建询价草稿，维护询价行（材料库选用 / 手工 / Excel 导入），PD 上传规格书和行级产品图，提交审批，采购主管通过（生成正式询价号）或驳回（填意见回到草稿）。

## 2. 范围

**范围内**：询价单表头 CRUD；第 1 轮询价行与附件；提交、通过、驳回、取消（发布前）；审批记录；列表（页签 + 筛选）、详情、待我审批；`InquiryAccessService`（按数据权限取单，查不到 404）；询价附件的文件访问解析器（内部侧）；`computeInquiryActions()`（03 §6）；邮件模板 `approval.request`、`approval.result`；审计；演示场景 D1、D2。

**范围外**：受邀名单与发布（M07）；供应商侧可见性（M08）；变更轮次的行编辑（M13，复用本模块的行与附件服务）。

## 3. 规则

| 编号 | 规则 |
|---|---|
| R06-1 | 创建必填：项目号（≤50）、标题、材料类别（有效启用）、币种（`currency` 字典）；负责人默认当前用户，PD 负责人可选。生成草稿号 `DR-yyyymmdd-nnnn`，同时建第 1 轮。同一项目号可以建多张询价单（#1）。 |
| R06-2 | 询价行来源：从材料库选（复制编码、中英文名、规格、单位、分类、品牌，材料必须启用）或手工录入（名称、规格、单位、分类必填）。数量 > 0，最多 4 位小数。分类必须有效启用（#21 询价行关联分类）。 |
| R06-3 | 行号从 1 连续；删除或调整顺序后重新编号。 |
| R06-4 | 只有单据为 `DRAFT` 时可以编辑表头、询价行和附件（提交后冻结，I-4）。 |
| R06-5 | 附件：`SPEC_DOC`（PDF/XLSX/XLS/图片）可挂整单或某一行；`PRODUCT_IMAGE` 只能挂在行上，每行最多 `imagesPerLine` 张（默认 10）。"复制到其他行"为目标行新增指向同一文件的挂载记录。 |
| R06-6 | 提交审批：至少 1 行，每行有分类、数量 > 0（`INQUIRY_NO_LINES` / `VALIDATION_FAILED`）。 |
| R06-7 | 通过：生成正式询价号 `RFQ-yyyymm-nnnn`；驳回：意见必填（`INQUIRY_REJECT_COMMENT_REQUIRED`），回到 `DRAFT`，编辑页顶部显示最近一次驳回意见。 |
| R06-8 | 审批人 = 有 `inquiry:approve` 且数据权限覆盖该单的用户；提交时给他们每人发一封 `approval.request`；审批结果发给负责人和创建人。 |
| R06-9 | 取消：原因必填；本模块覆盖未发布的情况（`DRAFT`/`PENDING_APPROVAL`/`APPROVED` 且第 1 轮未发布），发布后的取消在 M07 扩展。 |
| R06-10 | 所有接口叠加数据权限，范围外的单据返回 404。 |
| R06-11 | 询价行 Excel 导入的列：物料编码、物料名称 *、规格型号 *、单位 *、数量 *、材料分类编码 *、品牌、图纸/规格书编号、备注。物料编码匹配到启用的材料时，名称、规格、单位、分类取材料库的值；否则按手工行处理。导入的行追加在已有行之后；全部校验通过才写入。 |
| R06-12 | 状态动作全部记审计，审批记录可在详情页按时间线查看。 |

## 5. 前端

- `/inquiries`：页签（全部 / 草稿 / 待审批 / 待发布 / 等待报价 / 报价完成 / 评标中 / 评标完成 / 已取消）+ 筛选 + 表格（单号（有正式号显示正式号，否则草稿号）、项目号、标题、材料类别、显示状态、当前轮次、截止时间、负责人、创建时间）。
- `/inquiries/new`、`/inquiries/:id/edit`：一页分段——①基本信息；②询价行（"从材料库选用"对话框多选 + 填数量、"添加手工行"、"导入 Excel"、行内编辑、删除、拖动排序）；③规格书与产品图（整单规格书区 + 每行的规格书和产品图，显示"已上传 3/10"，"复制到其他行"）。底部"保存"和"提交审批"。驳回意见显示在顶部提示条。
- `/inquiries/:id`：表头卡片（单号、标题、项目号、材料类别、币种、负责人、PD、显示状态、截止倒计时）+ 按 `allowedActions` 显示的操作按钮 + 页签：明细与附件 / 审批记录 / 操作日志（M07 起增加"邀请供应商""供应商响应"等页签）。
- `/inquiries/approvals`：待审批列表，点进详情后在页面底部"审批操作"区填写意见并"通过 / 驳回回草稿"（参考 PPT #22）。
- 组件：`MaterialPickerDialog`（分类树 + 搜索 + 多选）、`LineFilesCell`、`ApprovalTimeline`。

## 6. 测试

- 建单：生成草稿号与第 1 轮；同一项目号建两张单都成功。
- 行：从停用材料选用被拒；分类停用被拒；排序后行号连续；导入混合匹配/手工行成功；导入错误整表拒绝。
- 附件：产品图第 11 张被拒；整单附件不能是产品图；复制到其他行。
- 状态：提交后编辑被拒（`INQUIRY_NOT_EDITABLE`）；驳回无意见被拒；驳回后可再编辑再提交；通过生成正式号且格式正确；邮件按审批人数量入队。
- 数据权限：SELF 的采购员看不到别人的单（列表不出现、详情 404）；DEPT、ALL 的可见性。
- `allowedActions`：草稿/待审批/已通过三种状态对 PD、采购员、采购主管分别返回正确的动作。
