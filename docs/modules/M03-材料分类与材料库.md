# M03 材料分类与材料库

> 覆盖：#21、#31、#29（产品规格模板） | 依赖：M02

## 1. 目标

树形材料分类（预置灯珠、灯外设等），材料库（名称、规格、单位、图片，可新增/编辑/停用），材料的 Excel 导入导出。询价行从这里选用（M06）。

## 2. 范围

**范围内**：分类树 CRUD、启停用、删除校验；材料 CRUD、启停用、图片；材料标准 Excel 模板的下载、导入、导出；材料图片的文件访问解析器（内部用户可读）；seed 06 §2.6、§2.7。

**范围外**：分类绑定 PPL 变体的界面与校验（M05 在分类编辑表单上补充；本模块 API 先接受 `pplVariantCode` 字段但不暴露在界面上，seed 直接写入）。

## 3. 规则

| 编号 | 规则 |
|---|---|
| R03-1 | 分类是任意深度的树（界面上建议不超过 5 级）；code 唯一（`^[A-Z0-9-]{1,30}$`），创建后不可改；中英文名称必填。不支持移动到其他上级。 |
| R03-2 | 分类的"有效启用"= 自己和所有上级都启用。停用某分类后，它和全部下级都不能被新选用（`CATEGORY_DISABLED`），已有数据照常显示。 |
| R03-3 | 只有没有下级、没有材料、没有询价行、没有供应商引用的分类才能删除，否则 `CATEGORY_HAS_CHILDREN` / `CATEGORY_IN_USE`。预置分类也遵守此规则。 |
| R03-4 | 材料 code 可手填（唯一，`MATERIAL_CODE_TAKEN`），留空自动生成 `MAT-000001`；名称、规格、单位、分类必填；单位必须是启用的 `unit` 字典项；分类必须有效启用；图片最多 1 张（`MATERIAL_IMAGE`）。 |
| R03-5 | 材料可停用/启用；停用的材料不能被询价行选用（`MATERIAL_DISABLED`）。 |
| R03-6 | 材料列表按分类筛选时包含所有下级分类；关键字匹配编码、中英文名称、规格。 |
| R03-7 | Excel 导入使用标准模板，列依次为：物料编码 / Material Code、物料名称 / Material Name *、英文名称 / English Name、规格型号 / Specification *、单位 / Unit *、材料分类编码 / Category Code *、品牌 / Brand、备注 / Remark。编码存在则更新、不存在或为空则新建；单位接受字典编码或中/英文名称；分类按编码匹配；全部校验通过才写入（R02-9）。 |
| R03-8 | 导出按当前筛选条件，列同导入模板，另加"状态 / Status"；导出文件可以直接改完再导入。 |
| R03-9 | 新建、编辑、启停用、删除、导入都记审计。 |

## 5. 前端

- `/materials/categories`：左侧可搜索的分类树（停用节点置灰），右侧编辑表单（上级分类只读、中文名、英文名、编码、排序、备注），按钮"保存 / 新增下级 / 新增顶级分类 / 停用或启用 / 删除"，参考 PPT #21。没有 `material:category:manage` 时只读。
- `/materials`：搜索框 + 分类下拉（树形选择）+ 状态；按钮"新增材料 / 导入 / 导出"；表格列：缩略图、编码、名称（按语言）、规格、单位、分类、品牌、状态、操作（编辑、停用/启用），参考 PPT #31。新增/编辑对话框含图片上传。
- 组件 `CategoryTreeSelect`（只允许选有效启用的节点），M04、M06 复用。

## 6. 测试

- 树：建三级分类；停用中间节点后，其下级不能被新材料选用；删除有下级/有材料的分类被拒。
- 材料：自动编码递增；重复编码被拒；停用材料后不可被选用（M06 再补询价侧用例）。
- 导入：新建 + 更新混合成功；单位用中文名匹配成功；分类编码不存在时整表拒绝并指出行列；表头顺序错误整表拒绝。
- 导出再导入（不改内容）结果为全部"更新"、数据不变。
