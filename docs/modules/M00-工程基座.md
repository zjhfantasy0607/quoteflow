# M00 工程基座

> 覆盖：#18（多语言框架）、#28（B/S 架构） | 依赖：无

## 1. 目标

搭好可运行的 monorepo 骨架，把后续所有模块都要用的基础设施一次做好：类型共享、配置校验、数据库迁移、错误格式、时钟、测试框架、前端布局与多语言。做完后 `npm run dev` 能起前后端，`npm run verify` 全绿。

## 2. 范围

**范围内**

1. 根目录：`package.json`（workspaces、脚本，见 01 §3.5）、`tsconfig.base.json`、`eslint.config.mjs`、`.prettierrc.json`、`.editorconfig`、`.gitignore`（含 `node_modules/`、`dist/`、`.env`、`apps/api/storage/`、`coverage/`、`playwright-report/`）。依赖版本严格按 01 §1。
2. `packages/shared`：package.json、tsconfig、`src/index.ts`、`enums.ts`（与 Prisma 枚举同值）、`errors.ts`（03 §3.1 全部错误码）、`time.ts`（`APP_TZ = 'Asia/Shanghai'`）、`status.ts` 骨架；vitest 配置；`tsc` 构建到 `dist/`（CommonJS）。
3. `apps/api`：
   - Nest 应用：`main.ts`（helmet、cookie-parser、全局前缀 `/api`、JSON 限制 1mb、监听 `127.0.0.1:API_PORT`）。
   - `config/env.ts`：zod 校验 01 §17 的全部变量，失败时打印具体项并退出。
   - `prisma/schema.prisma`（复制 `docs/schema.prisma`）+ 第一个迁移 `init`；`PrismaModule`（全局）。
   - `common/`：`AppException`、全局异常过滤器（03 §3）、`ZodValidationPipe`、`ClockService` + `TestClock`（支持 `set()` / `advance()`，生产环境禁用偏移）、分页工具（解析 page/pageSize，输出 `{ items, total, page, pageSize }`）。
   - `GET /api/health` → `{ status: 'ok', db: 'ok', time }`（执行 `SELECT 1`）。
   - jest 单元配置 + e2e 配置（`test/jest-e2e.json`，globalSetup 用 `DATABASE_URL_TEST` 执行 `prisma migrate deploy`；测试库名必须以 `_test` 结尾）；`test/helpers/`：`createTestApp()`、`resetDb()`；一个 health 的 e2e 用例。
   - `prisma/seed.ts` 骨架（M01 起往里加数据）；`package.json#prisma.seed = "tsx prisma/seed.ts"`（Prisma 6 会提示这个字段将来废弃，忽略，不要改用 prisma.config.ts）。
   - `.env.example`（01 §17）。
4. `apps/web`：
   - Vite + Vue + TS；`vite.config.ts`：`@quoteflow/shared` 别名到源码、`@` 别名到 `src`、`/api` 代理到 `http://127.0.0.1:3000`、`server.host = '127.0.0.1'`。
   - Element Plus 全量引入 + 图标；主题色变量（01 §5.1）；Pinia；Vue Router；vue-i18n（`legacy: false`，`locales/zh-CN|en-US/{common,errors,enums}.ts`）。
   - 三个布局骨架：`BuyerLayout`（顶栏 + 左侧菜单，菜单由路由表生成）、`PortalLayout`、`BlankLayout`；`LanguageSwitch` 组件（本模块先存 localStorage，M01 改为保存到账号）；`el-config-provider` 跟随语言。
   - axios 实例与拦截器（01 §5.3）；`utils/format.ts`：`formatDateTime()`（UTC+8）、`formatMoney()`、`pickName()`。
   - 通用组件先做 `PageHeader`、`StatusTag`；403、404 页；一个占位首页。
   - vitest 配置；单元测试：zh-CN 与 en-US 文案键集合完全一致。
5. `scripts/check-i18n.mjs`：扫描 `apps/web/src`（排除 `locales/`），`.vue`、`.ts` 中出现中日韩字符即失败并列出文件和行号。

**范围外**：登录与守卫（M01）、业务页面。

## 3. 规则

- R00-1 依赖版本必须与 01 §1 完全一致（精确版本，不写 `^`）。
- R00-2 shared 只依赖 `zod`、`decimal.js`，不使用任何 Node API。
- R00-3 业务代码禁止 `new Date()` 取当前时间，统一用 `ClockService.now()`。
- R00-4 所有异常输出 03 §3 的统一格式；未知异常不暴露堆栈给前端。
- R00-5 前端切换语言不刷新页面、不重建当前路由组件（表单输入保留）。

## 4. 测试

- e2e：`GET /api/health` 返回 200 且 `db = 'ok'`；不存在的路由返回 404 统一格式；故意抛出的 ZodError 返回 `VALIDATION_FAILED`。
- web：文案键一致性；`formatDateTime` 把 UTC 时间显示为 UTC+8。
- shared：错误码列表无重复。

## 6. 实施步骤

1. 根目录配置与 workspaces；`npm install`。
2. shared 包与构建。
3. api：配置校验 → Prisma（复制 schema、`migrate dev --name init`）→ 异常、管道、时钟、分页 → health → jest 与 e2e 框架。
4. web：Vite 工程 → Element Plus / Pinia / Router / i18n → 布局与语言切换 → axios → 工具函数 → 测试。
5. check-i18n 脚本；跑通 `npm run verify`；更新 `docs/进度.md`。
