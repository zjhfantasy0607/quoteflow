# M13 规格变更（新轮次）

> 覆盖：#12 | 依赖：M10（与 M11、M12 无先后要求，但要兼容议价关闭）

## 1. 目标

PD 发起规格变更 → 生成同一询价号下的新轮次（复制上一轮的询价行和附件）→ 修改规格、填写变更原因与变更内容 → 采购确认发布 → 供应商重新报价；上一轮整体作废、只读。提供轮次间的规格对比。

## 2. 范围

**范围内**：新建、编辑、放弃变更轮次；变更轮次的发布（"采购确认"）；作废上一轮（报价 VOID、议价关闭）；规格对比；邮件模板 `change.spec`；询价详情的轮次页签；门户显示轮次与变更说明；演示场景 D6。

## 3. 规则

| 编号 | 规则 |
|---|---|
| R13-1 | 新建变更轮次：需要 `inquiry:changeSpec`；询价单 `APPROVED` 且当前轮处于 `WAITING_QUOTES`/`QUOTES_CLOSED`/`OPENED`；已有 DRAFT 轮次时 `ROUND_DRAFT_EXISTS`。复制询价行（`sourceLineId`）与附件挂载，截止留空。 |
| R13-2 | DRAFT 变更轮次的询价行和附件按 M06 的规则编辑（`inquiry:create` / `inquiry:spec`），变更原因、变更内容可随时保存。 |
| R13-3 | 发布（"采购确认"）：需要 `inquiry:publish`；变更原因和变更内容必填（`ROUND_CHANGE_REASON_REQUIRED`）；受邀名单 ≥1；截止有效；冻结模板版本与变体（按当时激活的模板集）。 |
| R13-4 | 发布副作用（同一事务）：上一轮 → `SUPERSEDED`，其报价单 → `VOID`，进行中的议价关闭；`currentRoundNo` 切换；按当前受邀名单建报价单；上一轮也受邀的供应商收 `change.spec`（含变更原因、变更内容、新截止时间），本轮新增的供应商收 `invitation`。 |
| R13-5 | 上一轮如果从未开标，其报价永久密封（S-4）；如果开过标，采购方仍可查看当时的报价和比价（只读）。 |
| R13-6 | 规格对比：以新轮次的行通过 `sourceLineId` 匹配上一轮的行，比较名称、规格、单位、数量、分类、品牌、图纸编号、备注；标出新增行、删除行、修改字段，以及附件增删。 |
| R13-7 | 放弃变更：物理删除 DRAFT 轮次（需要 `inquiry:changeSpec`）。 |
| R13-8 | 历史轮次对采购方和供应商都只读（#12 历史轮次只读）；供应商在门户可以查看旧轮次自己的报价与规格（P-4）。 |
| R13-9 | 新建、编辑、放弃、发布都记审计。 |

## 4. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/inquiries/:id/rounds` | `inquiry:view` | 轮次列表（号、状态、截止、发布时间、报价数） |
| POST | `/api/inquiries/:id/rounds` | `inquiry:changeSpec` | `{ changeReason?, changeSummary? }` → 新 DRAFT 轮次 |
| PUT | `/api/inquiries/:id/rounds/:roundNo` | `inquiry:changeSpec` | `{ changeReason, changeSummary }` |
| DELETE | `/api/inquiries/:id/rounds/:roundNo` | `inquiry:changeSpec` | 仅 DRAFT 且 roundNo ≥ 2 |
| GET | `/api/inquiries/:id/rounds/:roundNo/diff` | `inquiry:view` | 与上一轮的规格对比 |

发布沿用 `POST /api/inquiries/:id/rounds/:roundNo/publish`（`RoundStateService` 按轮次号走不同分支）；询价行、附件接口沿用 M06。

## 5. 前端

- 询价详情增加轮次页签条：`第 1 轮（已作废）🔒只读`、`第 2 轮（进行中）`、`第 3 轮（变更草稿）`，切换后下方内容（明细、响应、比价等）都按所选轮次显示（参考 PPT #12）。
- "发起规格变更"按钮 → 进入变更草稿编辑：左侧"变更说明"（变更原因、主要变更内容），右侧"规格对比（第 N−1 轮 vs 第 N 轮）"表格，下方询价行与附件编辑区；底部"放弃变更"和"通知供应商重新报价"（即发布，需要选择截止时间）。
- 门户：报价详情显示"第 N 轮"，第 2 轮起显示变更说明和规格对比；旧轮次只读。

## 6. 测试

- 前置条件：DRAFT 单据、已完成的询价、已有变更草稿时新建被拒。
- 复制：新轮次行数、字段、`sourceLineId`、附件挂载与上一轮一致。
- 发布：缺变更原因被拒；成功后上一轮 `SUPERSEDED`、报价 `VOID`、议价关闭、`currentRoundNo` 切换、新报价单按名单创建；老供应商收 `change.spec`、新增供应商收 `invitation`。
- 密封：上一轮未开标时其报价仍不可见（加入密封测试集）；开过标的旧轮次报价可见。
- 对比：修改规格、删除一行、新增一行、更换附件，diff 结果准确。
- 放弃：草稿轮次被删除，当前轮不受影响。
- 门户：供应商能看到旧轮次自己的报价，但不能编辑。

## 7. 验收

- [x] 等待报价中 PD 发起变更、修改规格并说明原因，采购确认发布后，供应商收到变更邮件，在门户看到第 2 轮和规格对比，第 1 轮只读。
