# QuoteFlow 文档索引

这里是 QuoteFlow 询盘报价平台的开发文档，读者是实现者（Claude Code，跨会话靠这些文档保持设计一致）和评审者（用户）。**规格以本目录为准。** 根目录的 PPT 只是需求来源，里面的 UI 示意图是 AI 生成的示意，不是界面规格（原因见 [00-项目总览](00-项目总览.md) §5）。

## 阅读顺序

1. [00-项目总览](00-项目总览.md)：范围、角色、主流程、31 条需求对照、范围外清单、排期
2. [01-技术架构](01-技术架构.md)：技术栈与锁定版本、目录结构、开发环境（本机 Docker）、横切设计
3. [03-接口与编码约定](03-接口与编码约定.md)：所有模块共同遵守的写法、错误码
4. [05-状态机与权限](05-状态机与权限.md)：状态流转表、权限码、预置角色、密封与供应商隔离规则
5. 当前要做的模块文档 `modules/Mxx-*.md`
6. 按需查阅：
   - [02-数据模型](02-数据模型.md)，配套 [schema.prisma](schema.prisma)（已用 Prisma 6.19.3 校验，并在 PostgreSQL 15 上建表验证）
   - [04-PPL模板规范](04-PPL模板规范.md)，配套 [ppl-v0.json](ppl-v0.json)（70 列占位定义，脚本校验过）
   - [06-种子数据](06-种子数据.md)：基础数据与演示数据（来自 PPT 示例）

## 交付文档（M17）

面向客户与运维，放在 [交付/](交付/)：

- [部署手册](交付/部署手册.md)：镜像组成、配置项、本机 staging 首次部署、升级、备份恢复、生产部署清单、自动化测试命令
- [部署手册（不使用 Docker）](交付/部署手册-不使用Docker.md)：Linux 服务器上直接安装 Node.js、PostgreSQL、nginx，发布包、安装 / 升级 / 回滚脚本、systemd 服务、备份恢复、离线安装
- [用户手册](交付/用户手册.md)：按岗位（PD、采购员、采购主管、合同批准人、供应商）的操作说明，配演示环境截图
- [管理员手册](交付/管理员手册.md)：用户、角色权限、字典、系统参数（含密封授权角色、积分规则）、PPL 模板替换、邮件排障
- [验收清单](交付/验收清单.md)：31 条需求逐条的演示步骤、预期结果与对应的自动化测试；M17 的权限矩阵、安全复查、双语复查、性能抽查结果
- Word 版本在 [交付/word/](交付/word/)：由 `npm run docs:word` 从上面的 Markdown 生成（截图内嵌），Markdown 改了以后重新生成，不直接改 Word
