# 06 种子数据

客户真实数据还没有，先用 PPT 示例整理的灯具行业模拟数据。所有邮箱都用 `example.com` 系列域名，开发环境的邮件全部进 Mailpit，不会真正发出。

## 1. 原则

- `npm run db:seed`（`apps/api/prisma/seed.ts`）：**基础数据**，幂等（按 code / username upsert），可重复执行。各模块按需往里追加自己的部分。
- `npm run db:seed:demo`（`apps/api/prisma/seed-demo.ts`）：**演示数据**，只在没有任何询价单时运行（否则提示先 `npm run db:reset`）。业务单据**通过 service 方法创建**（`NestFactory.createApplicationContext`），保证状态和不变量都正确；需要"过去的时间"时用 `ClockService` 的偏移功能（仅非生产环境可用）。
- 开发账号统一密码 `Passw0rd!`，**只用于开发和演示**。
